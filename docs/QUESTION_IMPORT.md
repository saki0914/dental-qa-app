# 問題JSONの形式と登録

## 問題JSONの項目

JSONの最上位は問題の配列、または`{ "allQuestions": [...] }`にします。

| 項目 | 必須 | 内容 |
|---|---|---|
| `subject` | 必須 | 教科（80文字以内） |
| `subcategories` | 任意 | 分類の配列。先頭が「章・大分類」、2つ目以降が追加カテゴリ（各80文字以内） |
| `question` | 必須 | 問題文（500文字以内）。選択問題は選択肢もここに書く（下記） |
| `answers` | 必須 | 答えの配列。選択問題は正しい選択肢の記号 |
| `explanation` | 任意 | 解説（2000文字以内） |
| `orderedAnswers` | 任意 | `true`なら答えの順番も判定する（穴埋めの【a】【b】など）。省略時は`false` |
| `imageFile` | 任意 | 一括登録で一緒に選ぶ画像のファイル名（下記「画像付き問題の登録」） |

文字列の中の改行は`\n`で書きます。

## 選択問題

`question`の最後に選択肢を`a. `、`b. `、`c. `…の順で1行に1つずつ書き、`answers`に正しい選択肢の記号を書きます。この形の問題は、学習画面で選択肢のボタンとして表示され、押すとその場で正解・不正解と解説が出て「できる／まだ」に記録されます（iPhone版・iPad版とも。改訂14）。

```json
{
  "subject": "口腔解剖学",
  "subcategories": ["4章_発生", "鰓弓と神経支配", "国家試験形式"],
  "question": "鰓弓と神経支配の組み合わせで正しいのはどれか。\na. 第一鰓弓 — 顔面神経\nb. 第二鰓弓 — 舌咽神経\nc. 第三鰓弓 — 舌咽神経\nd. 第一鰓弓 — 舌咽神経",
  "answers": ["c"],
  "explanation": "【選択肢の解説】\na. 誤り。第一鰓弓は三叉神経の支配です。\nb. 誤り。…"
}
```

2つ選ぶ問題は、問題文に「2つ選べ。」と書き、`answers`を`["a", "d"]`のように2つにします。学習画面では2つ選んでから「解答する」を押します（答えを書く順番は問いません）。

JSONの項目は増やしていません。改訂13までに登録した同じ形の問題も、データを変えずにそのまま選択問題として表示されます。

選択問題として表示される条件:

1. 選択肢は問題文の**最後**に1行に1つずつ書く。選択肢の後に文を続けない（出典・注記・「2つ選べ」などは選択肢より前に書く）。
2. 記号は小文字の`a`から順に抜けなく（`a`、`b`、`c`、`d`…）、記号の後に`.`と空白を置く（全角の`ａ．`も可）。選択肢は2つ以上。
3. `answers`は選択肢の記号だけを書く（`"c"`。選択肢の文は書かない）。同じ記号を重ねない。
4. `orderedAnswers`は付けない（`true`にすると、選んだ順番も判定する）。

条件に合わない問題は、これまでどおり答えを書いて判定する記述式で表示されます。穴埋め（`前葉：口腔の上皮である【a】から発生する`）や、選択肢の行がなく図の記号を答える問題（`answers`が`"c"`）も記述式です。一括登録の「検証する」は、選択肢の行があるのに条件に合わない問題を警告として表示します（登録は止めません）。

### 問題を作るときのルール

問題の作り方（選択肢の書き方を含む）は「国試問題作成 汎用プロンプト v4.3」を参照してください。このファイルはアプリが読み込める形式の説明です。

## 画像付き問題の登録

### Macから一括登録する

問題JSONの各項目に、対応する画像のファイル名を`imageFile`で指定します。

```json
[
  {
    "subject": "歯内療法学",
    "subcategories": ["第1章", "歯髄診断"],
    "question": "画像の所見を答えてください。",
    "answers": ["不可逆性歯髄炎"],
    "explanation": "自発痛と温熱痛を確認します。",
    "orderedAnswers": false,
    "imageFile": "endo_001.png"
  }
]
```

1. 問題管理の一括登録でJSONを選択します。
2. 画像選択欄で、JSONから参照する画像をすべて選択します。iCloud Drive上の教科フォルダもファイル選択画面から開けます。
3. 「検証する」で対応漏れ、同名画像、重複問題、保存サイズを確認します。
4. 「検証OKデータを一括追加」で画像アップロードとFirestore保存を実行します。

`imageFile`は相対パスでの一致を先に試し、ブラウザがフォルダ情報を渡さない場合はファイル名で照合します。異なる教科に同名画像があると判定できないため、画像ファイル名は一括登録内で一意にしてください。

登録時は全画像をStorageへアップロードした後、問題と関連状態をFirestoreへ一括保存します。保存が失敗した場合は問題の追加を取り消し、追加途中のStorage画像も削除します。問題データはFirestoreの1ドキュメント上限に達しないよう自動的に複数文書へ分割されるため、JSONを手作業で分割する必要はありません。従来の1文書形式で保存された問題も引き続き読み込めます。

### iPhone/iPadから登録・更新する

問題管理で対象問題を選び、画像ファイルを選択して「更新」を押します。新しい問題は入力後に「追加」を押します。この経路は従来どおり1問題につき1画像を扱い、同じユーザーの`users/{uid}/questions/{questionId}/`配下へ保存します。

### Codexで教材画像を準備する場合

教科ごとのフォルダで画像を作成し、重複しない名前を付けます。JSONの`imageFile`にはそのファイル名を記載してください。macOSがCodexプロセスのiCloud Driveアクセスを拒否する場合でも、アプリ側のファイル選択画面から画像を選べます。
