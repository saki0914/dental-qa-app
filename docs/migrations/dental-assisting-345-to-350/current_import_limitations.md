# 現在の一括登録機能を移行に使わない理由

既存一括登録は、新しい教材を既存問題へ追加する用途には使えるが、正式345問から新正式350問への版移行には適さない。

- 298問を重複としてスキップし、52問を追加するため397問になる。
- 差分で廃止すべき旧問題47問が残る。
- 350問すべてで更新された `explanation` を既存レコードへ反映できない。
- 統合元・置換元の旧問題を安全な順序で廃止できない。
- 問題配列要素の既存 `id` と学習状態を、正式な対応表に従って維持・変換できない。
- 統合時の `null / 1 / 2` 集約規則を扱えない。
- 移行ロック、事前バックアップ、段階記録、同一migrationの冪等性、ロールバックがない。
- 画像17件を新350問と一体のリリースとして検証できない。

専用移行機能は、`app_migration_manifest_345_to_350.json` を唯一の問題対応正本とし、問題文類似度を対応付けに使わない。旧データを先に削除せず、バックアップと画像準備後に350問の完全状態を検証し、問題・進捗・設定を同じFirestore batchで切り替える。
