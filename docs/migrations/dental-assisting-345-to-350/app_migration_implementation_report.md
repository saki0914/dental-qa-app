## 学習状態

- 同じ認知方向を維持する問題は既存runtime idと状態を維持する。
- NEWと認知方向が変わるREPLACEDは決定的な新IDで未回答から開始する。
- MERGEDは、全元問題が1なら1、いずれかが2なら2、未回答を含み全て1でなければnullとする。
- 廃止runtime idの状態は最終progressから除去する。
- `wrongQuestionIds`、教科別件数、設定内IDを新350問に合わせて再計算する。

## 安全機構

- デフォルトはdry-run。
- `--formalization-report` と `--user-id` は必須。
- Emulatorとproductionを明示的に分離。
- production applyは `--apply`、`--environment production`、固定migration ID、確認文字列の4条件が必要。
- 移行元345問が正式runと完全一致しない場合は書込み前に停止。
- 新正式runのquestions SHA-256、images tree SHA-256、章別件数、未解決0件を検証。
- 問題文類似度を対応付けに使わない。
- ユーザー単位の移行ロックを取得。
- Git管理外でFinderから通常表示できる `migration-backups/` に、権限600のバックアップを作成。
- 画像をmigration固有パスへ準備してから問題データを切替。
- 問題・進捗・設定・完了記録はFirestore batchで切替。
- 完了済みmigrationは実体検証後、変更0件で終了。
- 画像準備後の擬似障害から同じmigration IDで再開可能。
- rollbackは問題、進捗、設定を復元し、新画像を除去する。

## 回答判定

- `orderedAnswers === true`: 順序を区別
- falseまたは未指定: 順不同
- NFKC、trim、英小文字化後に比較
- 配列の多重度を保持するため、`a,a` は `a,d` と一致しない
