# 回答比較回帰レポート

## 実装

`js/core/answer-comparison.js` に正規化と配列比較を分離した。

- 文字列化
- 前後空白除去
- Unicode NFKC
- 英字小文字化
- 既存互換のカタカナ・ひらがな差、長音差の吸収
- 波ダッシュ差の統一
- `orderedAnswers: true` のみ順序固定
- `orderedAnswers: false` または未指定は順不同
- Setではなくソート済み配列を比較し、重複数を保持

## 必須9ケース

1. `a,d` → `a,d`: 正解
2. 未指定で `d,a`: 正解
3. falseで `d,a`: 正解
4. trueで `d,a`: 不正解
5. `a,a`: 不正解
6. `a,c`: 不正解
7. ` A `、`ｄ`: 正解
8. `a`のみ: 不正解
9. `a,d,c`: 不正解

すべて合格した。

## 回帰

- 単一回答の完全一致: 合格
- `orderedAnswers: true` の複数穴埋め: 逆順を不正解として維持
- falseの記述式複数回答: 順不同として合格
- 既存単体テスト31件: すべて維持
- 現在の単体テスト: 52/52件合格
- iPad UIで4肢択2の逆順: 正解
- iPad UIで同一選択肢の重複入力: 不正解
